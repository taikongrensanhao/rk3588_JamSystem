# 实时训练与模型自主更新说明

## 1. 方案说明

本方案按老师要求拆成两部分：

1. 电脑训练服务：通过另一个网口与RK连接，接收RK上传的实采bin数据；点击界面“在线学习”后，按所选模式执行OrthoReg类增量混合学习、OrthoReg域增量混合学习或普通混合训练，并在验证准确率不下降时更新`MobileNetV2_Mixed.pth`。
2. RK3588显控界面：主界面增加“测试页面”按钮，进入测试页面后可选择“类增量混合学习”“域增量混合学习”或“混合训练（理想+实采）”，RK自动连接电脑训练服务、触发训练，训练完成后自动下载并部署最新`MobileNetV2_Mixed.pth`和`mobilenet_interference_rk3588.rknn`。

注意：RKNN模型主要用于NPU推理，不用于板端训练。实时训练建议在服务器上用PyTorch完成；RK端负责采集、上传、下载和推理。若服务器没有RKNN-Toolkit2转换环境，则只能更新`.pth`，RK端会继续使用旧`.rknn`或切换PyTorch推理。运行包内的`rknn_toolkit_lite2`是RK板端推理库，不是PC端模型转换工具。

本运行包同时保留老师提供的原始测试脚本和结果材料：

```text
MobileNet_OrthoReg_class_increment.py
MobileNet_OrthoReg_domain_increment.py
MobileNetV2_QPSKDataTrain_6classes_IncludeNone.pth
final_incremental_model.pth
final_merged_model.pth
*_confusion_matrix.png
```

样机实际在线学习调用的是适配版入口：

```text
train_incremental_orthoreg.py
```

该入口取消了原脚本中的`/root/autodl-tmp/...`硬编码路径，改为读取运行包中的固定数据目录。

## 2. 固定训练数据目录

服务器固定读取两个实采目录。`dataset_realworld`放历史实采数据，作为长期训练底座；`dataset_realtime`放RK新上传或新采集的数据，作为增量更新数据。

```text
JamSystem/dataset_realworld/
  none/
  single_tone/
  narrowband/
  wideband_barrage/
  comb/
  white_noise/
  noise_fm/
```

```text
JamSystem/dataset_realtime/
  none/
  single_tone/
  narrowband/
  wideband_barrage/
  comb/
  white_noise/
  noise_fm/
```

新数据按类别放入对应文件夹，例如：

```text
dataset_realtime/narrowband/20260605_001.bin
dataset_realtime/white_noise/20260605_002.bin
```

也可以由RK通过HTTP上传，服务器会自动保存到对应类别目录。

类增量混合学习和域增量混合学习会使用`dataset_realworld`、`dataset_realtime`中的实采数据；如果设置了`MIX_SIM_DATA_DIR`，也会同时加载理想/仿真数据目录中的样本。混合训练模式必须额外提供理想/仿真数据目录，该目录应包含`metadata.csv`和对应IQ样本文件。

## 3. 电脑端训练服务启动

在电脑Xterminal或Linux终端中进入`JamSystem`目录：

```bash
cd /home/pi/Desktop/run/JamSystem
chmod +x start_realtime_server.sh
./start_realtime_server.sh
```

如果电脑端已经安装RKNN-Toolkit2，并希望训练完成后自动生成新的RKNN模型，启动前加：

```bash
export JAMSYSTEM_ENABLE_RKNN_CONVERT=1
./start_realtime_server.sh
```

这会在每次训练通过后自动执行：

```bash
python export_mobilenet_to_onnx.py
python convert_onnx_to_rknn.py
```

如果在Windows电脑上运行，推荐直接执行运行包内的一键启动脚本：

```powershell
cd "E:\桌面迁移\无线电干扰识别与复原交付\01_运行包\JamSystem"
.\start_pc_training_server.ps1
```

该脚本默认使用`E:\miniconda3\envs\learnBP\python.exe`，监听`0.0.0.0:8008`，并自动接入理想/仿真数据目录：

```text
E:\桌面迁移\无线电干扰识别与复原交付\干扰样式识别流程图及参考代码
```

如果电脑路径不同，可在启动前设置：

```powershell
$env:JAMSYSTEM_PC_PYTHON="你的Python路径"
$env:JAMSYSTEM_SIM_DATA_DIR="你的理想或仿真数据目录"
.\start_pc_training_server.ps1
```

如果电脑或服务器环境已经安装了RKNN-Toolkit2，并希望在线学习训练完成后自动生成新的RKNN模型，启动前加：

```powershell
$env:JAMSYSTEM_ENABLE_RKNN_CONVERT="1"
.\start_pc_training_server.ps1
```

本电脑当前已在WSL的`Ubuntu`中配置了RKNN-Toolkit2环境：

```text
~/.venvs/rknn232
```

Windows训练服务启用`JAMSYSTEM_ENABLE_RKNN_CONVERT=1`后，会通过`convert_latest_model_to_rknn_wsl.ps1`调用该WSL环境完成RKNN转换。

启用后，训练成功会自动执行：

```text
MobileNetV2_Mixed.pth -> mobilenet_interference.onnx -> mobilenet_interference_rk3588.rknn
```

自动转换脚本会先生成`quant_dataset.txt`和`rknn_quant_data/*.npy`作为量化校准数据。转换成功后，`/model-info`中会显示`has_rknn=true`、`rknn_stale=false`，RK端在线学习脚本会自动下载并部署新的`.rknn`。如果当前Python环境没有`rknn.api.RKNN`，则会显示`rknn convert failed`，这说明需要在该环境安装RKNN-Toolkit2，或把训练服务迁移到已安装RKNN-Toolkit2的Linux/WSL/XTerminal环境。

也可以手动测试转换链路：

```powershell
python prepare_rknn_quant_dataset.py --sim-data-dir "E:\桌面迁移\无线电干扰识别与复原交付\干扰样式识别流程图及参考代码"
python export_mobilenet_to_onnx.py
python convert_onnx_to_rknn.py
```

检查电脑训练服务是否可连接：

```bash
curl http://服务器IP:8008/health
curl http://服务器IP:8008/model-info
```

手动触发训练：

```bash
curl http://服务器IP:8008/train-now
```

查看最近训练日志：

```bash
curl http://服务器IP:8008/last-log
```

## 4. RK端连接服务器

现在RK端优先通过界面操作：

1. 启动原有Qt界面。
2. 点击主界面的“测试页面”按钮。
3. 在测试页面中填写电脑训练服务地址，例如`http://192.168.137.2:8008`。
4. 填写RK新数据目录，例如`/mnt/usb/JamRecords`。
5. 选择学习模式：
   - 类增量混合学习：理想/仿真数据、realworld实采数据和新增噪声调频数据共同参与训练，基础6类QPSK模型增加噪声调频第7类，输出`final_incremental_model.pth`。
   - 域增量混合学习：理想/仿真数据、realworld实采数据和FM新域数据共同参与训练，基于7类模型适配FM调制域，输出`final_merged_model.pth`。
   - 混合训练：理想/仿真数据和realworld实采数据合并训练，输出`MobileNetV2_Mixed.pth`。
6. 点击“在线学习”。

点击后会自动执行：

```bash
cd /home/pi/Desktop/run/JamSystem
./jam_env/bin/python3 rk_online_learning_once.py \
  --server http://电脑IP:8008 \
  --upload-dir /mnt/usb/JamRecords \
  --mode class_increment \
  --train-now \
  --wait
```

其中：

- `--server`是电脑训练服务地址。
- `--upload-dir`是RK本地待上传新数据目录。
- `--mode`是学习模式，可选`class_increment`、`domain_increment`、`mixed_train`。旧参数`retrain`兼容为混合训练。
- `--train-now`表示立即触发电脑端训练。
- `--wait`表示等待电脑训练结束后再下载部署模型。

如果不用界面，也可以手动运行上述命令。

如果采集数据已经按类别分文件夹存放，脚本会从路径中自动识别类别。若是单个目录只上传一种类别，可强制指定类别：

```bash
./jam_env/bin/python3 rk_online_learning_once.py \
  --server http://电脑IP:8008 \
  --upload-dir /mnt/usb/JamRecords \
  --label narrowband \
  --mode class_increment \
  --train-now \
  --wait
```

## 5. 单独训练一次

如果只想单独执行一次混合训练，需要先指定理想/仿真数据目录。该目录应包含`metadata.csv`和对应IQ样本文件。

```bash
cd /home/pi/Desktop/run/JamSystem
export MIX_SIM_DATA_DIR=/path/to/simulation_dataset
export MIX_REAL_DATA_DIR=/home/pi/Desktop/run/JamSystem/dataset_realworld
export MIX_SAVE_PATH=/home/pi/Desktop/run/JamSystem/MobileNetV2_Mixed.pth
./jam_env/bin/python3 train_mixed_sim_realworld.py
```

训练完成后会生成或更新：

```text
MobileNetV2_Mixed.pth
model_version.json
```

## 6. RKNN更新

若电脑端具备RKNN-Toolkit2转换环境，可在启动服务前设置转换命令：

```bash
export JAMSYSTEM_RKNN_COMMAND='python3 export_mobilenet_to_onnx.py && python3 convert_onnx_to_rknn.py'
./start_realtime_server.sh
```

转换命令成功后，RK同步脚本会自动下载新的：

```text
mobilenet_interference_rk3588.rknn
```

若没有RKNN转换环境，服务器仍会更新`.pth`，但RKNN推理模型不会自动变化。

## 7. 推荐演示流程

1. 电脑通过另一个网口与RK连接，并启动`start_realtime_server.sh`。
2. RK运行采集程序，将实采数据保存到`/mnt/usb/JamRecords`或其他固定目录。
3. RK主界面点击“测试页面”。
4. 在测试页面填写电脑训练服务地址，选择“类增量学习”或“域增量学习”，点击“在线学习”。
5. RK上传新数据并触发电脑执行对应OrthoReg增量学习。
6. 电脑训练完成后，RK自动下载并替换新模型。
7. 重启GUI或重新启动识别程序，使新模型生效。
